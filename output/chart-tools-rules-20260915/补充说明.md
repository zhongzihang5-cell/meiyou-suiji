# 图表工具规则与接口补充说明

本版基于用户提供的6个绘图工具补充规则并扩展通用数据接口。红绿灯图由业务特殊处理，不新增对应工具。

## 已补齐的规则

1. 仅用原始记录或业务侧确认结果；不反推、不补值、不自行生成统计或状态映射。
2. 图表直接服务于当前反馈；新增记录优先展示同一记录项，图文日期、数值、单位及口径保持一致。
3. 根据数值趋势、分类状态出现情况、明确日期选型；仅用已注册且可用的组件，一次反馈合计最多1张图表。
4. 默认一个核心指标，增加指标须共同解释同一结论、有明确业务关联且已注册组件支持该组合。
5. 趋势／对比类至少2个同类、独立、可比较的有效数据点；台历至少1个相关明确日期。同日不同时间可计入，相同状态或数值不影响出图；null及展示刻度不计入。

## 接口变化

| 位置 | 变化 |
|---|---|
| 普通折线图、纵向柱状图的y_axis | 新增type=number分支，不套用体重的两位小数限制；保留date／weight分支 |
| 普通折线图、范围折线图、纵向柱状图、横向柱状图的series每个元素 | 新增必填metric对象，包含name、unit、precision；precision未指定时填null |
| 普通折线图、纵向柱状图、横向柱状图的绘图value | 支持number或null；范围折线图延续已有null支持 |
| 横向柱状图的y_axis | 保留date／weight，新增number／string行关联值类型；行关联值允许null，禁止给分类编造数字 |
| 柱状图的数值label | value为null时保留字段、填空字符串，客户端不展示数值标签 |

metric描述绘图数值。横向柱状图的y_axis.type只描述行关联值，柱体单位以series[].metric为准。metric.precision只控制展示，不授权模型修改传入原始value；未指定精度时保留来源精度。横向柱状图保留非负柱体和正整数max的现有能力，max不要求小数柱体取整。

## 接入与校验边界

本版是工具定义文件，没有改动客户端渲染程序或调用图表的服务端程序。新增必填metric后，原有数值图调用参数需要补齐该对象；接收方须支持number／string新分支及null展示约定，完成接入后才可向模型声明对应能力可用。

null处折线必须断开，不跨缺失值连线；柱状图保留对应刻度或行，不画柱体或数值标签。真实0值仍是有效数值。客户端仅格式化和渲染，业务数据、统计结果及业务阈值必须来自合规来源。

数据来源真实性、图文一致性、同类独立有效点计数、最多1张图表、数组对应关系、索引和区间边界、不同字段的单位与类型一致性，以及组件注册／可用性，需要调用方或服务端结合业务上下文校验。数组最小长度不能证明有足够的独立有效记录，故不把minItems=2作为出图门槛的替代实现。本版描述中已写明这些规则，但工具定义本身不等于已实现上述业务校验。

## 范围

沿用原6个工具名称。散点／区间图、台历没有新增调用字段。未新增红绿灯或组合图工具；多系列不自动代表多指标组合已获支持。不改动项目页面及锁定组件。
